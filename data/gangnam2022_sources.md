# 강남역 테스트베드 — 2022-08-08 호우 사상 · 자료 출처와 확실성 등급

이 문서는 `scenario_G_gangnam2022.json` 에 들어간 모든 숫자의 출처를 기록한다.
각 항목에 **확실성 등급**을 붙였다.

| 등급 | 뜻 |
|---|---|
| **[관측]** | 공식 관측·발표된 실측치. 그대로 사용 |
| **[공식분석]** | 서울시 등 기관의 공식 원인분석·제원. 그대로 사용 |
| **[재구성]** | 관측 앵커를 만족하도록 본 연구가 만든 값. 원자료 아님 |
| **[가정]** | 근거 문헌 없이 본 연구가 설정한 값. 교체 대상 |

## 1. 왜 원자료를 API 로 받지 못했는가

시도한 경로와 결과:

| 경로 | 결과 |
|---|---|
| 기상청 기상자료개방포털 `data.kma.go.kr` ASOS/AWS 시간자료 | **로그인 필요.** 비회원 다운로드 불가 |
| 기상청 API허브 `apihub.kma.go.kr` | **인증키 필수.** 휴대전화 인증 후 발급 |
| 공공데이터포털 `data.go.kr` ASOS 시간자료 OpenAPI | **인증키 필수** |
| 기상청 날씨누리 과거관측 페이지 | JS 렌더링, 표 미반환 |
| V-World / 서울 열린데이터광장 OpenAPI | **인증키 필수** |

→ **10분·시간 단위 AWS 원자료는 이 환경에서 받지 못했다.**
   대신 공식 발표·보도로 확인되는 **관측 앵커값**을 쓰고, 그 사이를 재구성했다.
   인증키를 발급받으면 `data/gangnam2022_rainfall.csv` 만 원자료로 교체하면 된다
   (스크립트·모형 수정 불필요).

## 3. 시설물 — 서울시 공식 침수원인 분석 [공식분석]

서울시는 강남역 일대 침수의 원인을 **4가지**로 공식 분석했다.

| # | 원인 | 본 모형에서의 반영 |
|---|---|---|
| ① | **항아리 지형** | `road` 의 V 에 반영 |
| ② | **강남대로 하수관로 설치 오류** | `sewer_reverse` 의 V, `sewer_reverse→road` 링크 |
| ③ | **반포천 상류부 통수능력 부족** | `banpo` 노드, `banpo→sewer_reverse` 링크 |
| ④ | **삼성사옥 하수암거 시공 오류** | `sewer_reverse` 의 V (②와 합산) |

### 3.1 항아리 지형 [공식분석]

- 강남역 일대 표고 **해발 12.2 m**
- 인근 논현동·역삼동보다 **17 m 이상 낮음**
- 한강 홍수 기준 수면 15.74 m 보다도 낮다
- 양옆이 높고 가운데가 낮은 깔때기형 저지대

### 3.2 역경사 하수관로 [공식분석]

- 삼성사옥–강남역 연결 지하보도 설치 과정에서
  **하수관로 하류측이 약 1.8 m 높게 역경사로 시공**
- 강남역 부근에서 물 흐름이 막혀 침수를 가중

→ 본 모형에서 `sewer_reverse → road` 링크의 **전달민감도 C 를 0.90 으로 높게** 둔
   직접 근거다. 통상적인 관로 월류와 달리 배수가 구조적으로 막힌 상태.

### 3.3 대응시설 [공식분석]

- **반포천 유역분리터널**: 2018 착공, **2021년 6월 완공**, 사업비 약 350억 원.
  서울남부터미널 일대 빗물을 반포천 중류로 분산
  → `banpo` 링크의 **백업 B** 에 반영(2022 사상 시점에 이미 가동 중)
- **용허리 빗물저류조**: 저지대 아파트 빗물 처리. 유입관로 추가 신설이 긴급대책에 포함
  → `detention` 노드

## 4. 노출성 E · 취약성 V [가정 — 근거 있는 설정]

E·V 는 공개 통계로 직접 산출할 수 있는 항목이 아니라, 위 [공식분석] 내용과
시설물 성격을 0~1 로 옮긴 **설정값**이다. 각 값의 근거는
`scenario_G_gangnam2022.json` 의 `note_ko` 와 `ev_basis_ko` 에 기록했다.

**중요** — `V` 는 **직접 노출분만** 담는다. 다른 시설물에서 전달되는 몫은 V 가 아니라
링크(K)가 담당한다(8월 설명자료 slide 16, 공통원인/상호의존 분리 원칙).
예: 강남역 역사는 강우에 직접 노출되지 않으므로 `V=0.12`(환기구 직접유입)이고,
실제 위험의 대부분은 `road → station` 전이로 들어온다.

## 5. 좌표 [가정]

평면 좌표는 **강남역 사거리 기준 상대 미터**이며, 공식 분석에 서술된 공간관계
(삼성사옥은 강남역 북측 강남대로변, 반포천 상류는 서측, 효성해링턴타워는 강남역
인근)를 반영한 **개념 배치**다. 실제 시설물 대장좌표가 아니다.

실좌표로 교체 시 `scenario_G_gangnam2022.json` 의 `map_xy` 만 바꾸면 된다.
